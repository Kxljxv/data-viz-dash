# AEA Graph Visualization Platform

The AEA Graph Visualization Platform is a comprehensive suite of tools designed for the exploration, analysis, and management of complex network data, particularly focusing on political relationships, proposals, and supporters.

## Purpose and Scope

The platform serves as an interactive environment where users can transform raw data into meaningful visual insights. Its primary goal is to make intricate connections between various entities transparent and easy to navigate, allowing for both broad overviews and deep analytical dives.

---

## Page-by-Page Description

### 1. Welcome and Introduction
This entry point provides a high-level overview of the platform's capabilities. It introduces users to the value of network visualization and the specific analytical tools available, guiding new and returning users toward the core functionalities.

### 2. Secure Access (Sign-In)
A dedicated area for authorized users to securely enter the platform. This ensures that sensitive data and administrative tools are protected and accessible only to registered individuals.

### 3. Main Dashboard
The central hub of the user experience. It provides a quick summary of the system status and direct shortcuts to the most frequently used tools. From here, users can transition seamlessly between visualization, analysis, and personal settings.

### 4. Project Selection
A specialized overview of all available data projects. Each project represents a unique dataset (e.g., a specific political convention or a thematic network). Users can view brief summaries of each project, including its scope and size, before selecting one to explore in detail.

### 5. Interactive Network Visualization
The core of the platform, where users engage directly with the data through a high-performance interactive environment.

*   **Search and Discovery Functionalities**: Controls that allow users to quickly locate specific entities or groups within the complex network.
*   **Visual Presentation Settings**: A comprehensive set of controls to customize the display. Users can adjust the scale of elements, toggle the visibility of labels and connections, and switch between different visualization modes to better highlight patterns.
*   **Grouping and Segmentation Controls**: Functionalities for organizing entities into meaningful categories. Users can define groups, assign colors, and filter the entire network to focus on specific subsets of data.
*   **Navigation and Interaction**: Advanced controls for exploring the visual space, including smooth zooming, panning, and the ability to center the view on specific points of interest.
*   **Contextual Information**: Interactive elements that provide detailed metadata about any entity or relationship selected within the network.
*   **Guided Exploration (Tours)**: An integrated feature that offers step-by-step walkthroughs. These tours explain the significance of specific data points and guide users through key findings within a project.

### 6. Analysis Tools Hub
A gateway to specialized analytical functions. This page provides access to tools that go beyond standard visualization, offering deeper insights into the structural properties of the data.

### 7. Density Analysis Workspace
A specialized tool for advanced data interpretation. It allows users to:
*   **Generate Density Maps**: Create visual representations of data concentration (heat maps) based on group memberships and relationships.
*   **Customize Analytical Parameters**: Controls to adjust the sensitivity, radius, and mathematical models used to calculate data density.
*   **Compare Datasets**: Functionalities to overlay and compare different groupings to identify overlaps or distinct patterns of concentration.
*   **Save and Export Findings**: Settings to store analysis results for future reference or sharing.

### 8. User Preferences and Profile
A personal space where users can manage their account information and customize their experience on the platform.

### 9. Administrative Overview (Admin only)
A high-level monitoring dashboard for platform administrators. It provides real-time statistics on system usage, user activity, and overall platform health.

### 10. User Administration (Admin only)
A management workspace for overseeing the platform's user base. It includes controls for:
*   **Managing User Accounts**: Viewing, updating, and organizing registered users.
*   **Access Level Management**: Functionalities for assigning and modifying roles and permissions to ensure appropriate data access.

### 11. Guided Tour Management (Admin only)
A creative workspace for administrators to design and refine the interactive tours. It includes tools for:
*   **Creating Storyboards**: Defining the sequence of steps, focal points, and annotations for a guided tour.
*   **Adjusting Visual Highlights**: Controls to precisely set the "camera" position and visual state for each step of the tour.
*   **Annotation Editing**: Functionalities to add descriptive text and visual markers to explain the data being shown.

### 12. Information and Support
*   **User Manual**: A comprehensive, step-by-step guide covering every functionality of the platform, designed to help users of all skill levels.
*   **Legal and Privacy Information**: Dedicated sections for the Imprint (Legal Notice) and Data Privacy Policy, ensuring transparency and compliance with data protection regulations.
